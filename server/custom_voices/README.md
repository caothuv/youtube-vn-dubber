# Thư mục giọng clone tùy chỉnh

- Bỏ file mẫu giọng (3-10 giây, giọng sạch, wav hoặc mp3) vào thư mục này,
  rồi dùng nút "➕ Thêm giọng mới" trong popup của extension (hoặc gọi
  POST /api/voices/add) để đăng ký giọng.
- Mỗi giọng clone sẽ xuất hiện trong danh sách chọn giọng của popup.
- File mẫu giọng và voices.json KHÔNG bị xóa khi cập nhật 1 chạm.
